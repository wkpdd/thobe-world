# عالم الثوب · Thobe World: logo files

All logos are vector drawings with the text converted to outlines. They print
sharp at any size and need no font installed.

| File | Use |
| --- | --- |
| `emblem-dark.svg`, `emblem-dark-2000.png` | **The main logo**: gold ring on ink. Signs, bags, packaging, Instagram posts |
| `emblem.svg`, `emblem-2000.png` | Same on a light background (transparent PNG) |
| `emblem-on-dark.svg` | Ivory and gold on transparent: over dark photos or fabric |
| `emblem-gold.svg`, `emblem-gold-2000.png` | One colour (gold): stamps, embroidery, foil, labels |
| `logo-horizontal.svg`, `logo-horizontal-2400.png` | Wide version for the website header, invoices, email signatures |
| `logo-horizontal-on-dark.svg`, `logo-horizontal-on-dark-2400.png` | Wide version on dark backgrounds |
| `icon.svg` | The ث monogram: favicon, small marks, photo watermark |
| `app-icon.svg`, `app-icon-1024.png` | Phone home-screen and app icon |
| `profile-1080.png` | Instagram, WhatsApp Business and Facebook profile picture (safe inside the circle crop) |
| `share-1200x630.jpg` | Picture shown when the site is shared on WhatsApp or Facebook |

**Colours**

| Name | Hex | Use |
| --- | --- | --- |
| Gold | `#B8913F` | On light backgrounds |
| Light gold | `#D8B873` | On ink |
| Ink | `#1F1B16` | Text and dark backgrounds |
| Ivory | `#FBF8F2` | Light backgrounds and text on ink |

**Typefaces:** Aref Ruqaa Bold for the Arabic name and Marcellus for "THOBE
WORLD". Both are under the SIL Open Font License and free for commercial use,
logos included (`OFL-Aref-Ruqaa.txt`).
